# Keep production inspection compact

- Read only the current script, theme and relevant scene helpers.
- Batch independent file reads. Use a contact sheet for visual review.
- Inspect navigation with the host's supported browser tools; capture full resolution only for footage or exact layout checks.
- Keep raw private captures out of the repository. Never dump private mailbox text or base64 images into chat.
- Rebuild and recheck the changed episode; reuse evidence only while source and host are unchanged.
